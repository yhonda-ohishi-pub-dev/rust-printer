## 現在の問題

### printpdf 0.8 API変更
`printpdf` クレートがv0.7→v0.8で大幅にAPI変更された。

**エラー箇所**: `src/pdf/generator.rs`

```rust
// 旧API (v0.7)
let (doc, page1, layer1) = PdfDocument::new(...);

// 新API (v0.8) - 修正が必要
let doc = PdfDocument::new("name");
let page = doc.add_page(...);
```

**修正が必要な箇所**:
1. `PdfDocument::new()` - 引数が変更
2. `Line` 構造体 - `points` の型が `Vec<(Point, bool)>` から `Vec<LinePoint>` に変更
3. `add_page()` の戻り値型も変更の可能性

### 次にやること

1. printpdf 0.8のドキュメント/ソース確認
   - https://docs.rs/printpdf/0.8.2/printpdf/

2. `src/pdf/generator.rs` を修正:
   - `PdfDocument::new()` の新しい使い方
   - `Line` 構造体の新しい形式
   - `add_page()` と `get_layer()` の使い方

3. または printpdf 0.7に戻す選択肢もある:
   ```toml
   printpdf = "0.7"
   ```
   ただしLine構造体のフィールドが異なる

## 備考

- Canon LBP221のプリンターIPは `.env` で `PRINTER_IP` として設定
- CUPSは `socket://[IP]:9100` で接続
- 日本語フォントは Noto Sans JP を使用予定
