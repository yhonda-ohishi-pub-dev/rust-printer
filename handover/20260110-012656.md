## 完了した作業

### 1. Canon LIPSLX ドライバーのインストール

Canon LBP221 は **PostScript 非対応** で、**LIPSLX/CARPS2** ドライバーが必要。

**ダウンロードソース**:
- URL: https://canon.jp/support/software/os/select/ir/linux-lipslx-drv-v620-jp-02tar
- ダウンロードリンク: `https://pdisp01.c-wss.com/gdl/WWUFORedirectTarget.do?id=MDEwMDAwNDE1ODQz&cmp=ACM&lang=JA`
- ファイル名: `linux-lipslx-drv-v620-jp` (67MB)
- deb パッケージ: `cnrdrvcups-lipslx_6.20-1.02_amd64.deb`

**インストール手順**:
```bash
# ドライバーをダウンロード
wget -O lipslx-driver.tar.gz "https://pdisp01.c-wss.com/gdl/WWUFORedirectTarget.do?id=MDEwMDAwNDE1ODQz&cmp=ACM&lang=JA"
tar xzf lipslx-driver.tar.gz

# cups-sidecar にコピー
docker cp linux-lipslx-drv-v620-jp/x64/Debian/cnrdrvcups-lipslx_6.20-1.02_amd64.deb cups-sidecar:/tmp/

# 依存パッケージをインストール
docker exec cups-sidecar apt-get update
docker exec cups-sidecar apt-get install -y --fix-broken

# ドライバーをインストール
docker exec cups-sidecar dpkg -i /tmp/cnrdrvcups-lipslx_6.20-1.02_amd64.deb
```

**依存パッケージ** (自動インストール):
- cups-bsd
- libgtk-3-0
- lsb-release

### 2. CUPS プリンター設定

```bash
# 旧プリンターを削除して再設定
docker exec cups-sidecar lpadmin -x Canon_LBP221
docker exec cups-sidecar lpadmin -p Canon_LBP221 -E -v socket://172.18.21.60:9100 -m CNRCUPSLBP221ZJ.ppd -o printer-is-shared=false
docker exec cups-sidecar lpadmin -d Canon_LBP221

# 確認
docker exec cups-sidecar lpstat -p -d
# 出力: printer Canon_LBP221 is idle. enabled since...
```

```bash

# Cargo.lock を生成
cd rust-app && cargo generate-lockfile
```

## 残存する問題

### PDF生成時のフォント読み込みエラー

**症状**:
```json
{"status":"error","message":"PDF generation failed: Failed to add font"}
```

**原因分析**:
1. フォントファイル `fonts/NotoSansJP-Regular.ttf` は存在する (296KB)
2. Docker ボリュームマウント `./fonts:/app/fonts:ro` は正しく設定されている
3. `printpdf::add_external_font()` がフォント読み込みに失敗

**考えられる原因**:
- scratch イメージでの `std::io::Cursor` の動作問題
- printpdf 0.7 と Noto Sans JP フォントの互換性問題
- フォントファイルの破損または不完全

**調査・対策の方向性**:

1. **別のフォントで試す**
   - IPAフォント、M PLUS フォントなど

2. **Dockerfile を修正**
   - scratch → alpine に変更してデバッグ
   - フォントをイメージに埋め込む

3. **printpdf のバージョン変更**
   - 0.8.x にアップグレードまたは別のPDFライブラリを検討
