#### 主なAPI変更点（実際に使用したもの）
```rust
// Before (0.7)
layer.use_text(text.to_string(), size, Mm(x), Mm(y), font);
layer.add_line(line);

// After (0.8)
vec![
    Op::StartTextSection,
    Op::SetFontSize { font: font_id.clone(), size: Pt(size) },
    Op::SetTextCursor { pos: Point::new(Mm(x), Mm(y)) },
    Op::WriteText { font: font_id.clone(), items: vec![TextItem::Text(text.to_string())] },
    Op::EndTextSection,
]

vec![Op::DrawLine { line }]
```

**注意**: GitHubのprintpdf最新版とcrates.ioの0.8.2ではAPIが異なる
- GitHub: `Op::SetFont` + `Op::ShowText`
- crates.io 0.8.2: `Op::SetFontSize` + `Op::WriteText`
