## 今回のセッションで解決した問題

### 1. CUPS IPP認証エラー (`client-error-not-authorized`)

**問題**: RustアプリからCUPSへのIPP Print-Jobリクエストが認証エラーで拒否された

**原因**: プリンターの共有設定が無効だった (`printer-is-shared=false`)

**解決**:
```bash
docker exec cups-sidecar lpadmin -p Canon_LBP221 -o printer-is-shared=true
```

**cupsd.conf の変更**:
```
<Location /printers>
  Order allow,deny
  Allow all
  AuthType None
</Location>

<Location /printers/Canon_LBP221>
  Order allow,deny
  Allow all
  AuthType None
</Location>
```

### 2. Canon LIPSLXドライバーの再インストール

`docker-compose down -v` でボリュームを削除したため、ドライバーを再インストール。

**手順**:
```bash
# 依存パッケージをインストール
docker exec cups-sidecar apt-get update
docker exec cups-sidecar apt-get install -y cups-bsd lsb-release --no-install-recommends

# ドライバーをインストール (libgtk-3-0は無視)
docker cp /tmp/linux-lipslx-drv-v620-jp/x64/Debian/cnrdrvcups-lipslx_6.20-1.02_amd64.deb cups-sidecar:/tmp/
docker exec cups-sidecar dpkg --ignore-depends=libgtk-3-0,libgtk-3-0t64 -i /tmp/cnrdrvcups-lipslx_6.20-1.02_amd64.deb

# プリンター設定
docker exec cups-sidecar lpadmin -p Canon_LBP221 -E -v socket://172.18.21.60:9100 -m CNRCUPSLBP221ZJ.ppd -o printer-is-shared=true
docker exec cups-sidecar lpadmin -d Canon_LBP221
```

## 未解決の問題: プリンターがデータを処理できない

### 症状

1. **LIPSLXドライバー使用時**: `Broken pipe` エラー
   - CUPSがPDFをラスター化してLIPSLX形式に変換
   - プリンターに送信中に接続がリセットされる
   - プリンターがデータを拒否している

2. **RAWモード使用時**: ジョブは送信されるが印刷されない
   - PDFがそのままプリンターに送信される
   - プリンターがPDFを直接処理できない

### テスト結果

| モード | ジョブ送信 | プリンター接続 | 印刷出力 |
|--------|----------|--------------|---------|
| LIPSLX (CNRCUPSLBP221ZJ.ppd) | OK | Broken pipe | NG |
| RAW (生PDF送信) | OK | Waiting for printer | NG |

### ログ抜粋

**LIPSLXモード**:
```
[Job 2] Error reading back-channel data: Connection reset by peer
[Job 2] Unable to write print data: Broken pipe
```

**RAWモード**:
```
[Job 3] Wrote 2464 bytes of print data...
[Job 3] Print file sent.
[Job 3] Waiting for printer to finish.
```

## 考えられる原因と対策

### 1. プリンターのネットワーク設定

- **確認事項**: プリンターがRAWポート(9100)での印刷を許可しているか
- **対策**: プリンターの管理画面でネットワーク印刷設定を確認

### 2. プリンターの言語設定

Canon LBP221は以下をサポート:
- UFR II (Canon独自)
- LIPS LX

**確認事項**: プリンターがどのPDL(ページ記述言語)モードになっているか

### 3. ドライバーのバージョン/互換性

- 現在のドライバー: `cnrdrvcups-lipslx_6.20-1.02_amd64.deb`
- **対策**: Canon公式サイトで最新ドライバーを確認

### 4. 別の印刷方法を検討

1. **UFR II ドライバー**: Canon UFR II ドライバーを試す
2. **IPP Everywhere**: プリンターがIPP Everywhereに対応していれば直接IPP印刷
3. **Windows経由**: Windowsマシンに接続して共有プリンタとして使用

## コマンドチートシート

```bash
# コンテナ起動
docker-compose up -d

# ボリュームを含めて再作成 (設定変更後)
docker-compose down -v && docker-compose up -d

# ドライバー再インストール (ボリューム削除後に必要)
docker cp /tmp/linux-lipslx-drv-v620-jp/x64/Debian/cnrdrvcups-lipslx_6.20-1.02_amd64.deb cups-sidecar:/tmp/
docker exec cups-sidecar dpkg --ignore-depends=libgtk-3-0,libgtk-3-0t64 -i /tmp/cnrdrvcups-lipslx_6.20-1.02_amd64.deb

# プリンター設定
docker exec cups-sidecar lpadmin -p Canon_LBP221 -E -v socket://172.18.21.60:9100 -m CNRCUPSLBP221ZJ.ppd -o printer-is-shared=true
docker exec cups-sidecar lpadmin -d Canon_LBP221

# プリンター状態確認
docker exec cups-sidecar lpstat -t

# ジョブ確認/キャンセル
docker exec cups-sidecar lpstat -o -W all
docker exec cups-sidecar cancel -a

# ログ確認 (デバッグモード)
docker exec cups-sidecar cupsctl --debug-logging
docker exec cups-sidecar cat /var/log/cups/error_log | tail -50

# 軽量PDFでテスト
docker exec cups-sidecar bash -c 'cat > /tmp/test.ps << "EOF"
%!PS
/Helvetica findfont 24 scalefont setfont
100 700 moveto (Hello Printer Test) show
showpage
EOF
ps2pdf /tmp/test.ps /tmp/test.pdf'
docker exec cups-sidecar lp -d Canon_LBP221 /tmp/test.pdf
```
