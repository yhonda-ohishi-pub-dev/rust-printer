## printpdf 0.7 → 0.8 主なAPI変更点

| 項目 | 0.7 | 0.8 |
|------|-----|-----|
| ドキュメント作成 | `PdfDocument::new(title, w, h, layer)` → tuple | `PdfDocument::new(title)` |
| ページ作成 | `doc.add_page(w, h, layer)` | `PdfPage::new(Mm(w), Mm(h), ops)` |
| フォント追加 | `doc.add_external_font(reader)` → `IndirectFontRef` | `ParsedFont::from_bytes()` → `doc.add_font()` → `FontId` |
| レイヤー | `doc.get_page(idx).get_layer(idx)` | 不要（Opsベース） |
| テキスト | `layer.use_text(text, size, x, y, font)` | `Op::SetFont` + `Op::ShowText` |
| 線描画 | `layer.add_line(Line { points: Vec<(Point, bool)> })` | `Op::DrawLine { line: Line { points: Vec<LinePoint> } }` |
| 保存 | `doc.save(writer)` | `doc.save(&PdfSaveOptions, &mut warnings)` → `Vec<u8>` |

## 重要なコード変更パターン

### Line構造体の変更
```rust
// Before (0.7): Vec<(Point, bool)>
let points = vec![
    (Point::new(Mm(x1), Mm(y1)), false),
    (Point::new(Mm(x2), Mm(y2)), false),
];

// After (0.8): Vec<LinePoint>
let points = vec![
    LinePoint { p: Point::new(Mm(x1), Mm(y1)), bezier: false },
    LinePoint { p: Point::new(Mm(x2), Mm(y2)), bezier: false },
];
```

### テキスト描画の変更
```rust
// Before (0.7)
layer.use_text(text.to_string(), size, Mm(x), Mm(y), font);

// After (0.8)
vec![
    Op::StartTextSection,
    Op::SetFont {
        font: PdfFontHandle::External(font_id.clone()),
        size: Pt(size),
    },
    Op::SetTextCursor { pos: Point::new(Mm(x), Mm(y)) },
    Op::ShowText { items: vec![TextItem::Text(text.to_string())] },
    Op::EndTextSection,
]
```

### generate() メソッドの新しい形
```rust
pub fn generate(&self, items: &[Item]) -> Result<Vec<u8>> {
    let mut doc = PdfDocument::new("Travel Expense Report");
    let font = ParsedFont::from_bytes(&self.font_bytes, 0, &mut Vec::new())
        .ok_or_else(|| anyhow::anyhow!("Failed to parse font"))?;
    let font_id = doc.add_font(&font);

    let mut pages = Vec::new();
    for item in items {
        let ops = self.build_page_ops(&font_id, item)?;
        let page = PdfPage::new(Mm(w), Mm(h), ops);
        pages.push(page);
    }

    let pdf_bytes = doc.with_pages(pages).save(
        &PdfSaveOptions::default(),  // subset_fonts: true がデフォルト
        &mut Vec::new(),
    );

    Ok(pdf_bytes)
}
```
