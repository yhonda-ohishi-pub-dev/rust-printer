## 実施内容

### CUPSサイドカー削除・RAW TCP印刷への移行

プリンター `172.18.21.60` に対して `nc` で直接PDF送信テストを実施し、ポート9100へのRAW TCP送信で印刷が成功することを確認。これを受けて、CUPSサイドカーを削除してシンプル化を実施した。

#### テスト結果
- **ポート9100 (RAW TCP)**: A4 PDF、封筒サイズ PDF ともに印刷成功
- **ポート631 (IPP)**: PX-M650F用に引き続き対応

#### 変更ファイル
1. **rust-app/src/print/ipp_client.rs** - 全面書き換え
   - `PrintMode::Raw` - ポート9100へのRAW TCP送信（デフォルト）
   - `PrintMode::DirectIpp` - ポート631へのIPP送信（PX-M650F用）

2. **rust-app/src/api/handlers.rs**
   - CUPSモードをRAWモードに置換
   - `printer_name` → `printer_ip` に変更

3. **rust-app/src/main.rs**
   - 環境変数変更: `CUPS_SERVER`/`CUPS_PORT`/`DEFAULT_PRINTER` → `PRINTER_IP`

4. **docker-compose.yml / docker-compose.prod.yml**
   - `cups-sidecar` サービス削除
   - `PRINTER_IP` 環境変数に統一
   - ボリュームやネットワーク設定をシンプル化

5. **cups-sidecar/** - フォルダごと削除

6. **fonts/** - `NotoSansJP-Regular.ttf` → `ipaexg.ttf` に変更

## 新しい環境変数

| 変数 | 説明 | デフォルト |
|------|------|-----------|
| `PRINTER_IP` | プリンターのIPアドレス | `172.18.21.60` |
| `LISTEN_ADDR` | サーバーリッスンアドレス | `0.0.0.0:8081` |
| `FONT_PATH` | フォントファイルパス | `/app/fonts/ipaexg.ttf` |

## API使用方法

### RAW印刷（デフォルト）
```bash
curl -X POST http://localhost:8081/print \
  -F "document=@test.pdf" \
  -F "printer_ip=172.18.21.60"
```

### Direct IPP印刷（PX-M650F用）
```bash
curl -X POST http://localhost:8081/print \
  -F "document=@test.pdf" \
  -F "printer_ip=192.168.x.x" \
  -F "use_direct_ipp=true" \
  -F "paper_size=A4"
```
