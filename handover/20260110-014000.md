## 今回のセッションで解決した問題

### 1. フォントファイルの問題

**問題**: `fonts/NotoSansJP-Regular.ttf` が実際には HTML ファイル（GitHub のダウンロードページ）だった

**解決**: IPAゴシックフォント (`ipaexg.ttf`) をダウンロードして使用

```bash
# ダウンロードコマンド
cd fonts
wget -q "https://moji.or.jp/wp-content/ipafont/IPAexfont/IPAexfont00401.zip" -O ipa.zip
python3 -c "import zipfile; z=zipfile.ZipFile('ipa.zip'); z.extractall('.'); z.close()"
cp IPAexfont00401/ipaexg.ttf .
rm -rf IPAexfont00401 ipa.zip
```

**変更ファイル**: `rust-app/src/main.rs` (フォントパスを `ipaexg.ttf` に変更)

### 2. CUPS IPP接続エラー

**問題**: `Request from "172.20.0.3" using invalid Host: field "cups-sidecar:631"`

**原因**: CUPS が Docker のコンテナホスト名を認識しなかった

**解決**: `cups-sidecar/cupsd.conf` に `ServerAlias *` を追加

```
# Allow Docker container hostnames
ServerAlias *
```

**注意**: `cups-data` ボリュームが `/etc/cups` をマウントしているため、設定変更後は `docker-compose down -v` でボリュームを削除する必要がある

### 3. プリンターIP設定

**問題**: デフォルトのプリンターIPが `192.168.1.100` になっていた

**解決**: 手動で正しいIPに更新

```bash
docker exec cups-sidecar lpadmin -p Canon_LBP221 -v socket://172.18.21.60:9100
```

## 残存する課題

### 1. Canon LIPSLX ドライバー

Canon LBP221 は PostScript 非対応のため、LIPSLX ドライバーが必要。現在は RAW モードで PDF を直接送信しているが、プリンターが PDF を処理できるか未確認。

前回のセッションでドライバーをインストールしたが、ボリュームを削除したため再インストールが必要になる可能性がある。

**ドライバーインストール手順** (前回の引き継ぎより):
```bash
# ドライバーをダウンロード
wget -O lipslx-driver.tar.gz "https://pdisp01.c-wss.com/gdl/WWUFORedirectTarget.do?id=MDEwMDAwNDE1ODQz&cmp=ACM&lang=JA"
tar xzf lipslx-driver.tar.gz

# cups-sidecar にコピー
docker cp linux-lipslx-drv-v620-jp/x64/Debian/cnrdrvcups-lipslx_6.20-1.02_amd64.deb cups-sidecar:/tmp/

# ドライバーをインストール
docker exec cups-sidecar dpkg -i /tmp/cnrdrvcups-lipslx_6.20-1.02_amd64.deb

# プリンター再設定
docker exec cups-sidecar lpadmin -x Canon_LBP221
docker exec cups-sidecar lpadmin -p Canon_LBP221 -E -v socket://172.18.21.60:9100 -m CNRCUPSLBP221ZJ.ppd -o printer-is-shared=false
docker exec cups-sidecar lpadmin -d Canon_LBP221
```

### 2. docker-compose.yml のプリンターIP

`docker-compose.yml` のデフォルトプリンターIPを修正が必要:

```yaml
# 現在
PRINTER_URI=socket://${PRINTER_IP:-192.168.1.100}:9100

# 推奨
PRINTER_URI=socket://${PRINTER_IP:-172.18.21.60}:9100
```

または `.env` ファイルで `PRINTER_IP=172.18.21.60` を設定。
